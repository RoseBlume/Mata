# Phase 1 — typed semantic IR (additive)

The new `ir` module extends the original Phase 0 artifact without changing existing intrinsic identifiers or removing existing APIs. It contains extended scalar and vector metadata; typed pointers with explicit memory spaces and access rights; arrays and records; typed expressions; branches, bounded-range loops, while loops, statements, returns and workgroup barriers; functions; and complete compute kernel declarations for CUDA C++, HIP C++, and OpenCL C. It does not allocate or execute GPU resources.

**Implemented:** Numeric type descriptions (`Bool`, 8/16/32/64-bit signed/unsigned, F16/F32/F64, BF16), vectors with lane counts 2/3/4/8/16, fixed arrays, typed pointers and records; typed expression nodes, buffer reads/writes, basic arithmetic, work index builtins; statements, functions, kernels and validation of identifiers, duplicate names, invalid dimensions and some type mismatches; source generation and explicit failures when a requested capability is unavailable.

**Important limits:** Some types are representable in the IR but deliberately cannot be emitted on a given backend yet; BF16 and CUDA/HIP F16 require dedicated vendor-native lowering. Arrays currently render only in parameter declarations. OpenCL F16/F64 require supported compiler/device features (no feature negotiation in Phase 1). GLSL/HLSL shader entry-point binding models and WGSL global resources aren't generated in this phase, and the backend returns `Unsupported` rather than misleadingly declaring complete support. Uniformity verification, control-flow dataflow/type inference, full semantic validation, structured type layout and GPU runtime validation are **Phase 2+** work. In particular, a compute work-item ID is modeled as 64-bit in the IR; WGSL 64-bit support is not assumed. User-defined call targets and variable scopes aren't exhaustively validated yet. This implementation is a foundation, not a complete cross-backend compiler.

**Try the tests:** `cargo test --test phase1_ir` and `cargo test`. **No external Rust dependencies added.**
