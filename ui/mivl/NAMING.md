# Official language name: MIVL

**MIVL** stands for **Mata Interface View Language**.

- Language: MIVL
- Markup: `.mivl`
- Rust runtime: `mivl`
- CLI: `mivl`
- Build-time compiler: `mivl-build`
- Rust inclusion macro: `mivl::include_modules!();`
- Command attribute: `#[mivl::command]`

See [MIGRATION.md](MIGRATION.md) for the MQML rename instructions.
